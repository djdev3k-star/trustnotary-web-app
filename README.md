# Trust Notary Website

A modern, fully responsive website for Trust Notary services, built with React and optimized for all devices from mobile phones to desktop computers.

## What This Is

This is your professional notary business website showcasing your services, pricing, testimonials, and contact information. The site provides an elegant, app-like experience on mobile devices while maintaining full functionality on tablets and desktop computers.

## Key Features

### Fully Mobile Responsive
- Automatically adjusts layout and content for phones, tablets, and desktops
- Touch-friendly interface optimized for mobile users
- Smooth transitions between different screen sizes
- App-like experience on mobile devices

### Professional Design
- Elegant color scheme with gold accents (#cdad7d) on dark navy (#142631)
- Premium serif fonts (Cormorant Garamond & EB Garamond) for sophisticated look
- Smooth animations and interactive elements throughout
- Professional imagery and video backgrounds

### Complete Service Showcase
- Hero section with video background
- About section highlighting your business approach
- Detailed service listings with transparent pricing
- Texas Notary Fee Schedule
- Client testimonials with Google 5-star ratings
- Contact form for appointment requests
- Service categories clearly organized

### Sections Included
1. **Navigation** - Smooth scrolling to all sections
2. **Hero** - Eye-catching video background with call-to-action
3. **About** - Your business philosophy
4. **Visual Showcase** - Key service highlights
5. **Services** - 6 service packages with detailed pricing
6. **Testimonials** - 3 Google reviews showcasing client satisfaction
7. **Schedule** - 4 service types with imagery
8. **Contact** - Professional contact form
9. **Services List** - Comprehensive list of all notary solutions
10. **Footer** - Contact information and credentials

## Mobile Optimizations Made

All sections now feature:
- Responsive font sizes (smaller on mobile, larger on desktop)
- Adaptive padding and spacing
- Properly stacking layouts on narrow screens
- Touch-friendly buttons and links
- Readable text with proper contrast
- Optimized images and content flow
- Mobile-specific badge positioning in hero section

## Technical Details

**Built With:**
- React 18 - Modern JavaScript framework
- Vite - Lightning-fast build tool
- Tailwind CSS - Utility-first styling
- Framer Motion - Smooth animations
- Lucide React - Professional icons

**Responsive Breakpoints:**
- Mobile: 0-639px
- Tablet: 640-1023px
- Desktop: 1024px and above
